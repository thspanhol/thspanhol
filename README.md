## Sobre mim

Desenvolvedor Full-Stack com experiência em aplicações web completas — do banco de dados à interface. Trabalho com **Java + Spring Boot** e **Angular** no dia a dia, mas transito bem pelo ecossistema **Node.js** e **React** também.

Antes de migrar para tech, passei pela área jurídica e por uma posição de Analista de Sistemas no Sicredi — combinação que me deixou com olhar analítico, atenção a processos e facilidade para comunicação com áreas de negócio.

- 🏢 Full-Stack Developer @**Technocorp**
- 🎓 Tecnólogo em ADS *(em andamento)*
